# مشروع بورصة BOURSA

منصة عربية متجاوبة لعرض السيارات في موريتانيا، مع لوحة إدارة مرتبطة بـ Supabase.

## محتويات المشروع
- `index.html` واجهة الموقع العامة.
- `styles.css` تصميم الواجهة العامة.
- `app.js` البحث والفلترة والتفاصيل وتسجيل طلب الاهتمام.
- `admin.html` شاشة دخول ولوحة المدير.
- `admin.css` تنسيق لوحة المدير.
- `admin.js` المصادقة وإدارة السيارات والأقسام والطلبات ورفع الصور.
- `config.js` إعداد اتصال الموقع (يحتاج Project URL ورقم التواصل قبل التشغيل).
- `config.js.example` نموذج إعداد الاتصال.
- `supabase/schema.sql` إنشاء الجداول والفهارس وسياسات RLS ومخزن الصور.
- `supabase/add-admin.sql` إضافة حساب المدير المحدد مسبقاً.

## 1) إعداد Supabase
1. أنشئ مشروعاً في https://supabase.com/.
2. افتح SQL Editor ثم New query.
3. انسخ محتوى `supabase/schema.sql` وشغّله كاملاً.
4. أنشئ حساب المدير من Authentication > Users > Add user باستخدام بريدك وكلمة مرور قوية.
5. تأكد أن UUID للحساب هو `4eab9224-2d5b-4c84-8548-f51487d48869`. إذا كان هذا هو الحساب الذي أنشأته، افتح SQL Editor وشغّل محتوى `supabase/add-admin.sql`.
6. من Project Settings > API أو زر Connect انسخ `Project URL`.
7. تم وضع Publishable Key الذي زودتنا به في `config.js` و`config.js.example`:
   `sb_publishable_BBfTrnI9YUllgKpvVjByw__LCRYnt-`
8. افتح `config.js` وضع رابط مشروعك الحقيقي مكان `ضع_هنا_PROJECT_URL`.
9. استبدل `222XXXXXXXX` برقم واتساب موريتاني بصيغة دولية من دون + أو مسافات، واستبدل `XXXXXXXX` برقم العرض.

**مهم:** لم يقدّم المستخدم Project URL أو رقم واتساب/الهاتف بعد؛ لذلك بقيت هذه القيم كعناصر نائبة، ولا يمكن اعتبار الاتصال مكتملاً حتى تعبئتها.

## 2) تسجيل الدخول إلى لوحة الإدارة
1. افتح `admin.html` بعد إعداد `config.js`.
2. سجّل الدخول بالبريد وكلمة المرور اللذين أنشأت بهما حساب Supabase Auth.
3. يجب أن يكون UUID الحساب موجوداً في `public.admin_users` حتى يحصل على صلاحية الإدارة.

## 3) تشغيل ونشر الموقع
- ضع ملفات المشروع في جذر موقع ثابت.
- افتح `index.html` للواجهة العامة و`admin.html` للوحة الإدارة.
- يمكن نشر المشروع على Vercel أو Netlify أو GitHub Pages.
- تأكد من رفع `config.js` إلى بيئة النشر بعد إكماله؛ فهو مستثنى من Git بواسطة `.gitignore`.

## 4) الأمان
- المفتاح الموجود في `config.js` هو Publishable Key مخصص للواجهة العامة؛ لا تضع `service_role` أو `secret` key في ملفات المتصفح.
- اترك RLS مفعّلة. لا تعالج أخطاء الصلاحيات بإيقافها.
- حماية الإدارة الفعلية تتم في قاعدة البيانات عبر `admin_users` وسياسات RLS.
- طلبات الاهتمام عامة للإدخال فقط؛ المدير وحده يستطيع قراءتها وإدارتها. قبل الإطلاق التجاري أضف CAPTCHA أو حماية معدل الإرسال عبر Edge Function.
- صور السيارات في bucket عام حتى يستطيع الزوار مشاهدتها؛ الرفع والتعديل والحذف للمديرين فقط.
- المنصة لا تنفذ فحصاً فنياً آلياً للسيارات؛ لا تعرض السيارة على أنها مفحوصة إلا بعد التحقق منها فعلياً.

## 5) حدود النسخة الحالية
لا تتضمن النسخة الحالية مدفوعات إلكترونية أو تقسيطاً فعلياً أو حسابات مستقلة للبائعين أو نظام تحقق فني آلي. هذه ميزات مستقبلية تحتاج تطويراً مستقلاً.
